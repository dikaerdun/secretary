## 环境与路径

- 系统：Ubuntu 22.04.5 LTS。
- 系统 Python：3.10.12；项目使用隔离的 Python 3.12.13，不替换系统 Python。
- 应用目录：`/opt/personal-secretary`。

## 配置交接

用户在本地 `secretary/.env` 填写以下字段：

- `WECOM_BOT_ID`
- `WECOM_BOT_SECRET`
- `WECOM_ALLOWED_USER_IDS`（企业成员账号）
- `DEEPSEEK_API_KEY`

配置填好后通过本次 SSH 的 SFTP 加密通道传到专用应用目录，远端权限设为 `600`。不将配置内容打印到工具输出、日志、文档或源码包。

企业微信后台页面被浏览器站点安全策略拦截，不能由本任务自动操作。机器人需由用户在已经登录的后台手动创建，选择 API 长连接并限定本人使用。
